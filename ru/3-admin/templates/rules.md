## 2.3.__id__.4. Область применения {#2-3-__id__-4}
```
Контекст, где действует правило.
Границы применения: где оно обязательно, где допускается, а где не применяется.
```

---

## 2.3.__id__.5. Формулировка правила {#2-3-__id__-5}
```
Чёткое, однострочное, проверяемое правило.
Может быть приведено в строгой форме:
- Условие → Обязательное действие
- Запрет → Контроль
- Ограничение → Допустимый диапазон
```

```

Почему именно такая формулировка и границы.
```

## 2.3.__id__.7. Условия применения {#2-3-__id__-7}
```
Чёткие условия, при которых правило вступает в силу.
Предусловия, триггеры, классы ситуаций.
```

## 2.3.__id__.8. Исключения {#2-3-__id__-8}
```
Перечень исключений, когда правило НЕ применяется.
Определяются явно, чтобы избежать двусмысленности.
```

## 2.3.__id__.9. Проверяемость и критерии соблюдения {#2-3-__id__-9}
