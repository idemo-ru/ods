**0.1 ∙ __month__ 2025**

**Контекст C**  
Область: компьютерное зрение  
Цель: классификация изображений (CIFAR-10)  
Ограничения: ≤ 10 М параметров, inference ≤ 50 мс на CPU  
Критерий успеха R: Top-1 accuracy (выше — лучше)

**Эталонный агент E** (по Допущению 04, состояние 2025)  
Максимально эффективный набор ChangeOperators в заданных ограничениях:  
- EfficientNet-B0 + knowledge distillation + AutoAugment + MixUp  
R(E) = 86.3 %

**Три реальные модели-агента**

|------------|--------------------------------------------------|-----------|----------|------------------|-----------------------------|

**Выводы для ML-практики в терминах ODS**

1. Модель B — лучший кандидат на публикацию/деплой: R ≥ R(E) и высокая S → одновременно эффективное и оригинальное решение.
2. Модель C — типичный «исследовательский» результат: интересна научному сообществу (S ↑↑), но не годится в продакшн без доработки.
3. Модель A — «рабочая лошадка», легко воспроизводима, минимальные риски.

**Практическое использование правила**
- При отборе моделей в production: фильтр R ≥ R(E) − δ  
- При отборе в исследовательскую публикацию: максимизировать S при R ≥ порога
- При найме ML-инженера/исследователя: сравнивать S кандидатских решений с S(E) за одинаковый R
