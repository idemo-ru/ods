> Документ предназначен для позиционирования ODS в текущем информационном пространстке по данной теме а так же для дальнейгей проработки темы с учётом текущих знаний.
>💡 Примечание: таблица отражает текущее состояние анализа. Новые концепции и данные будут интегрироваться по мере развития ODS.
{.is-info}

- ODS: опыт = системная метрика + динамический механизм оптимизации

| Сравниваемая теория / концепция | Аналог в ODS | Совместимость | Различие | Новое / полезное в ODS |
|--------------------------------|--------------|---------------|----------|-----------------------|
| Классическая системная теория (например, Кибернетика, Wiener) | ChangeFlow, граф опыта | Совместимо: обе рассматривают динамику системы и обратные связи | Классические теории часто статичны, нет метрики сомнения | Введена Doubt(S,VC) как метрика альтернатив и ёмкости инструментов |
| Системный анализ (Operations Research, PERT, Decision Trees) | MetaChangeFlow | Совместимо: анализ вариантов и принятие решений | Классический анализ детерминирован, редко учитывает контекст и адаптивное сомнение | MetaChangeFlow позволяет рекурсивно генерировать и тестировать новые альтернативы |
| Теория знаний / Expert Systems (Rule-based, Knowledge Graphs) | Граф опыта (Nodes ±1/0, ассоциативные связи) | Совместимо: хранение опыта и ассоциаций | Классические системы редко имеют динамическое обновление параметров сомнения | Динамическая настройка A0, α, T0, C на основе реального опыта |
| ML / AI Experience Replay (RL, Memory Buffers) | Граф опыта + MetaChangeFlow | Совместимо: хранение прошлых событий и использование в будущем | Классический Replay часто не учитывает альтернативы и их стоимость | Интеграция с Doubt(S,VC) позволяет выбирать оптимальные пути и избегать ложной уверенности |
| Антропоцентрические подходы к субъективности | Субъективность = функция ChangeOperators и контекстов | Частично совместимо: обе концепции оценивают различия поведения | Антропоцентризм отсутствует, субъективность формализована | Функциональная, количественная метрика S, применимая ко всем системам |
| Теории сомнения / неопределённости (Dempster-Shafer, Bayesian) | Doubt(S,VC) | Совместимо: неопределённость / сомнение присутствует | Bayesian часто требует вероятностной априорной модели, Dempster-Shafer — комбинирует источники | Простая формула сомнения, легко настраиваемая, учитывает альтернативы и ёмкость инструментов |


Классические теории опыта:
+-----------------+      +-----------------+      +-----------------+
|  История        |----->|  Прецеденты     |----->|  Ассоциативная  |
|  (события)      |      |  (s,a,r,s')     |      |  память / KG    |
+-----------------+      +-----------------+      +-----------------+
         \                    |                        /
          \                   |                       /
           \                  v                      /
            \         +-----------------+            /
             -------->|  Feedback /     |-----------
                      |  Local rules    |
                      +-----------------+

             (Все процессы обычно детерминированные, без метрики сомнения)

ODS — Experience как функциональная система:
+-----------------+     +-----------------+     +---------------------+
| Граф опыта      |---->| ChangeOperators |---->| Viewpoint (Context) |
| (Nodes ±1/0)    |     | (операторы)     |     | Hierarchy           |
+-----------------+     +-----------------+     +---------------------+
          |                     |                        |
          |                     |                        |
          v                     v                        v
     +---------------------------------------------------------+
     |                  Doubt(S,VC)                           |
     |  - функция альтернатив и ёмкости инструментов         |
     |  - учитывает цену ошибки и насыщение по альтернативам  |
     +---------------------------------------------------------+
                              |
                              v
                     +---------------------+
                     |  MetaChangeFlow     |
                     |  - Генерация новых  |
                     |    альтернатив      |
                     |  - Рекурсивная      |
                     |    оптимизация      |
                     +---------------------+
                              |
                              v
                     +---------------------+
                     |  Обновление графа   |
                     |  опыта (Nodes + EV) |
                     +---------------------+

Ключевая идея:
- Все классические элементы опыта сохраняются.
- ODS добавляет:
    * Doubt(S,VC) — метрику сомнения и оценки альтернатив.
    * MetaChangeFlow — механизм адаптивной генерации новых альтернатив.
    * Динамическую интеграцию контекстов и ChangeOperators.
- Результат: автоматическая, функциональная эволюция опыта без субъективности.
