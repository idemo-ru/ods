## Сравнение с теорией процесса Уайтхеда
| Аспект            | Теория процесса Уайтхеда                               | ODS                                               |
|------------------|--------------------------------------------------------|--------------------------------------------------|
| Основная единица  | Actual occasions (drops of experience, concrescence via prehensions) | ChangeFlow-6 (6 фаз изменения) + ChangeOperators (процессные механизмы) |
| Онтология         | Process-relational: becoming > being; relationality, creativity | Dynamic systems: устойчивые изменения, LifeCycle-6 |
| Реальность        | Events/occasions с experience (panexperientialism), eternal objects | Процессы реализации операторов через Viewpoint/TIL |
| Время/изменение   | Concrescence → satisfaction → objectification       | Collect → ... → evaluate; каузальная последовательность |
| Креативность      | Novelty из prehensions + God (lure)                 | Стохастический Viewpoint + Граф Опыта, emergent TIL |
| Сходства          | Процесс первичнее субстанции; relational; эмерджентность | Процессные механизмы; циклы изменения           |
| Различия          | Panexperientialism, God, eternal objects            | Без experience/God; вычислительная (Λ-Phy как вариант Wolfram) |

ODS — современная, secular, computational версия process philosophy Уайтхеда.

## Сравнение с философией Бергсона
| Аспект            | Философия Бергсона                                        | ODS                                                |
|------------------|-----------------------------------------------------------|---------------------------------------------------|
| Основная единица  | Durée (чистая длительность), élan vital (жизненный порыв) | ChangeFlow-6 (процесс изменения) + LifeCycle-6   |
| Онтология         | Becoming > being; время как качественная длительность     | Процесс первичнее субстанции; циклы изменения    |
| Изменение         | Творческая эволюция, интуиция vs интеллект              | Реализация ChangeOperators через Viewpoint/TIL; стохастика |
| Время             | Непрерывное, нелинейное, творческое                     | Каузальная последовательность фаз; эмерджентное из редукций (Λ-Phy) |
| Креативность      | Élan vital как новизна                                     | Emergent/Hybrid операторы, ΔViewpoint            |
| Сходства          | Процесс/становление центрально; критика статичных моделей | Процессные механизмы; динамика систем           |
| Различия          | Витализм, интуиция, durée (невычислимая)                | Secular, computational (Λ-Phy), дискретные фазы |

ODS — современная, вычислительная версия process philosophy Бергсона без витализма.
