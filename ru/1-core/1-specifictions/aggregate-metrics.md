## 2.2.12.1. Основное {#1-1-3-1}
Документ описывает единый реестр агрегатных скалярных метрик, являющихся координатами состояния системы.

> *Версия: doc.2.2.12.v.1.31.6 ∙ июнь 2025*<br/><br class="hidden-wiki"/>
> *Текущий LifeCycle:* `Draft` → Candidate → Stable → Canonical<br class="hidden-wiki"/>
> *Фаза:*. `Birth` → Develop → Climax → Degrade → Turn → End( death | transform )<br/><br class="hidden-wiki"/>
> *Текущий ChangeFlow:* #31<br  class="hidden-wiki"/>
> *Фаза:*  `collect` → analyze → forecast → decide → implement → evaluate<br/><br class="hidden-wiki"/>

### 1.1.3.x.1. Назначение {#1-1-3-x-1}
Дать **единообразный шаблон**, куда **любой домен** вставляет **собственные скаляры** и **сразу видит**, как они лягут в **DegradeVector** и далее в **фазовую аксиому**.  
Цель — **убрать «табличную магию»** и сделать шаблон **машиночитаемым** и **peer-reviewable**.

### 1.1.3.x.2. Универсальные координаты уровня 0 {#1-1-3-x-2}

| Универсальная координата | Что фиксируем | Ед. изм. / диапазон | Источник доменных данных | Правило нормализации |
|--------------------------|---------------|---------------------|--------------------------|----------------------|
| **DomainScore (DS)** | Степень «износа/усталости» системы | [0,1] | Любой доменный индикатор (список ниже) | 0 = идеальное, 1 = точка невозврата |
| **τ_stable** | Длительность непрерывного плато DS ≤ 0,2 | время | Тайм-стемпы наблюдений | Укажите **минимальный** τ_stable,min **своего домена** |
| **τ_phase** | Длительность непрерывного превышения доменного порога деградации | время | Те же тайм-стемпы | Укажите **минимальный** τ_phase,min **своего домена** |
| **ClassTag** | Класс сложности на момент рождения | строка C-{N}-{name} | Наблюдаемое событие (список ниже) | Фиксируется **один раз** |

### 1.1.3.x.3. Реестр доменных доноров (плейсхолдеры) {#1-1-3-x-3}

| ID-донора | Домен | Физический смысл | Базовая метрика | Нормализация |
|-----------|-------|------------------|-----------------|--------------|
| **DS_BIO** | биология | Доля живых/функциональных элементов | live / total | 0 = все живы, 1 = все мертвы |
| **DS_STAR** | звёзды | Доля оставшегося топлива | H_now / H_init | 0 = только что зажглась, 1 = водород исчерпан |
| **DS_CODE** | ПО | Доля успешных CI/CD-прогонов | success / total | 0 = все зелёные, 1 = все красные |
| **DS_CORP** | компании | Доля удержания ключевых сотрудников | 1 – (ушедшие / штат) | 0 = никто не ушёл, 1 = ушли все |
| **DS_TOKEN** | крипто-экономика | Доля активных валидаторов | active / total | 0 = все онлайн, 1 = все оффлайн |
| **DS_CITY** | городское | Доля работающих критических инфра-узлов | up / (up + down) | 0 = всё работает, 1 = всё мертво |

> **Правило добавления нового донора:**
> 1. Метрика **однозначно нормализуема** в [0,1],  
> 2. Есть **публичный способ измерения** (open-data или open-sensor),  
> 3. Указаны **единицы времени** для τ_stable,min и τ_phase,min.

### 1.1.3.x.4. Плейсхолдеры временных порогов {#1-1-3-x-4}

| ClassTag | τ_stable,min (плейсхолдер) | τ_phase,min (плейсхолдер) | Пример заполнения |
|----------|-----------------------------|---------------------------|-------------------|
| C-1-Natural | {{T_STABLE_MIN}} лет | {{T_PHASE_MIN}} лет | 10⁶ / 10⁵ |
| C-2-Bio | {{T_STABLE_MIN}} с | {{T_PHASE_MIN}} с | 1 / 0,5 |
| C-3-Colony | {{T_STABLE_MIN}} с | {{T_PHASE_MIN}} с | 60 / 30 |
| C-4-IndMind | {{T_STABLE_MIN}} ч | {{T_PHASE_MIN}} ч | 1 / 0,5 |
| C-5-FullMind | {{T_STABLE_MIN}} ч | {{T_PHASE_MIN}} ч | 24 / 12 |
| C-6-Super | {{T_STABLE_MIN}} дн | {{T_PHASE_MIN}} дн | 365 / 180 |

> **Как заполнить:**
> 1. Возьмите **3–5 репрезентативных** систем своего домена,  
> 2. Измерьте **эмпирическое** минимальное плато,  
> 3. Опубликуйте **датасет + код**, иначе значение считается **недействительным**.

### 1.1.3.x.5. Шаблон доменного отчёта (YAML-фрагмент) {#1-1-3-x-5}

```yaml
domain: "stellar_physics"
system: "Sun"
class_tag: "C-1-Natural"
donor_id: "DS_STAR"
DS_formula: "H_mass_now / H_mass_ZAMS"
τ_stable_min: 1e6   # years
τ_phase_min: 1e5    # years
source_data: "https://doi.org/10.0000/stellar_ds_2025"
code: "https://github.com/xxx/ds-sun"
```
