## 1.1.4.3. Термины и определения {#1-1-4-3}
- **ChangeOperator** — вечный, неизменный инструмент преобразования X → Y при контексте C
- **L/P/S/E-operators** — Local / Parent / Sibling / External (по источнику доступа)

## 1.1.4.4. Область применения {#1-1-4-4}
Применимо ко всем системам, обладающим ChangeFlow (биологические, когнитивные, социальные, технические, ИИ).  
Не применимо к статичным объектам без изменения и репликации.

## 1.1.4.5. Типология ChangeOperators {#1-1-4-5}
| Тип        | Описание                              | Примеры                              |
|------------|---------------------------------------|--------------------------------------|
| Natural    | Независимы от наблюдателя             | Логика, математика, физика           |
| Constructed| Искусственно созданные                | Алгоритмы, языки, нейросети       |
| Emergent   | Из взаимодействия систем              | Деньги, мемы, социальные нормы       |
| Embedded   | Встроены в архитектуру                | Рефлексы, инстинкты, предобучка      |
| Meta       | Действуют над другими операторами     | Viewpoint, рефлексия                 |
| Hybrid     | Комбинация типов                      | Человеческий мозг, LLM               |
| Transient  | Существуют только в одном ChangeFlow  | Одноразовый промпт                   |
| Forbidden  | Доступ заблокирован системой          | Деструктивные паттерны               |

## 1.1.4.6. Классификация по доступу {#1-1-4-6}
| Тип      | Обозначение | Источник              | Уровень инновационности |
|----------|-------------|-----------------------|--------------------------|
| Local    | L           | Текущий цикл          | Низкая                   |
| Parent   | P           | Наследование          | Базовая                  |
| Sibling  | S           | Смежные системы       | Средняя                  |
| External | E           | Удалённые системы     | Высокая / прорыв         |

## 1.1.4.7. Минимальный обязательный набор по фазам ChangeFlow {#1-1-4-7}
| Фаза         | Обязательные ChangeOperators                     |
|--------------|--------------------------------------------------|
| collect      | Сенсорные / наблюдательные                       |
| analyze      | Логические, модельные, семантические             |
| forecast     | Математические, вероятностные                    |
| decide       | Разрешение неопределённости                      |
| implement    | Физические / исполнительные (локальные)          |
| evaluate     | Метрики, сравнения                               |

## 1.1.4.9. Заключение {#1-1-4-9}
ChangeOperators — онтологически первичная сущность.  
Все системы, прогресс и креативность — это лишь разные способы подключения к этому вечному множеству через Viewpoint и TIL.
