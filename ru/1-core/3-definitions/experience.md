## 1.3.7.3. Термин и формулировка {#1-3-7-3}

**Опыт (Experience)** — онтологически первичное локальное свойство наблюдателя конкретного экземпляра системы, представляющее собой динамический причинно-контекстный граф (Experience Graph), где каждая нода фиксирует онтологически полную ассоциацию наблюдаемого ChangeFlow-6: Intent-Flow → Context → использованные ChangeOperators → Result с универсальной оценкой (+1 полезно / 0 бесполезно / -1 опасно), исключительно через локальные механизмы восприятия, обеспечивая онтологическую причинность оптимизации последующих ChangeFlow в фазе evaluate.

## 1.3.7.4. Область применения {#1-3-7-4}

Применимо ко всем системам классов 2–6 с фазой evaluate.  

Для систем классов 0–1 граф опыта минимален (≈ один цикл), обеспечивает базовую функциональность без накопления.

### 1.3.7.5.1. Типы опыта

| Тип                  | Описание                                                                 | Носитель                          | Механизм доступа и актуализации                          | Характеристики динамики                          | Примеры                                                                 |
|----------------------|--------------------------------------------------------------------------|-----------------------------------|----------------------------------------------------------|-------------------------------------------------|-------------------------------------------------------------------------|
| **Локальный**       | Индивидуальные причинно-контекстные ассоциации, накопленные непосредственно экземпляром через собственные механизмы восприятия в реальном времени каждого ChangeFlow. | Локальный наблюдатель конкретного экземпляра системы | Прямой и немедленный: фиксируется автоматически в фазе evaluate; доступен для runtime-использования в последующих циклах. | Динамически усиливается (+1), ослабевает (0) или подавляется (-1); самоочищение графа. | Личные сенсорные впечатления организма; индивидуальные воспоминания человека; результаты fine-tuning конкретной копии LLM. |
| **Консолидированный** | Сжатая композиция преимущественно успешных (+1) локальных ассоциаций других экземпляров, параллельных или родительских систем, переданная через наследование, контексты или встроенные структуры. | Конкретный экземпляр системы (как носитель сжатой информации) | Потенциальный: становится частью локального графа опыта только после актуализации через локальное восприятие, активацию или интеграцию в ChangeFlow. | Преимущественно статичен до актуализации; после — интегрируется в динамику локального графа (+1 доминируют). | ДНК как сжатый опыт вида (инстинкты); культурные нормы и знания через C_org/C_info; pre-training как консолидированные +1 ассоциации "вида" моделей LLM. |

> Консолидированный опыт сохраняет онтологическую локальность: носитель всегда конкретный экземпляр, передача осуществляется через C-Layer или наследование, без нарушения уникальности индивидуального Experience Graph.

## 1.3.7.6. Атрибуты / свойства {#1-3-7-6}

- **Онтологическая причинность**: связи в графе строго причинны (Intent-Flow → Context → Operators → Result), а не корреляционны; фиксируют "почему" и "как" результат возник в данном контексте.
- **Локальность и уникальность**: принадлежит только экземпляру, фиксирует только локально наблюдаемое.
- **Актуализация**: консолидированный опыт становится локальным только через локальное восприятие.
- **Динамика**: +1 ассоциации усиливаются (runtime-доступ); 0 ослабевают; -1 подавляются/архивируются (самоочищение графа).
- **Непрямое влияние**: только через evaluate → выбор ChangeOperators и обновление DegradeScore.
- **Минимальность**: у простых систем ограничивает накопление → базовая вариативность поведения.

## 1.3.7.7. Связи с другими терминами {#1-3-7-7}

- **Родительские**: ChangeFlow-6 (evaluate), Система (наблюдатель), Context (источник данных).
- **Дочерние**: Experience Graph, локальный/консолидированный опыт.
- **Связанные**: DegradeScore (обновление по результатам), ChangeOperators (выбор на основе ассоциаций).

## 1.3.7.8. Примеры и иллюстрации {#1-3-7-8}

- **Элементарная система**: минимальный граф → вариативность без накопления.
- **Организм**: локальный (сенсорика) + консолидированный (ДНК как сжатые +1 ассоциации вида).
- **Человек**: локальный (воспоминания) + консолидированный (культура, история через C_org/C_info); актуализация через чтение/практику.
- **LLM**: локальный (fine-tuning) + консолидированный (pre-training как +1 ассоциации "вида").

## 1.3.7.10. Заключение {#1-3-7-10}

Опыт обеспечивает онтологическую причинность обучения: от вариативности элементарных систем к целенаправленной эволюции сложных, через локальные причинные ассоциации в evaluate, сохраняя строгую локальность наблюдателя и деантропоморфизм.  

Опыт влияет на DegradeScore исключительно в evaluate: +1 снижает (рост устойчивости), 0/-1 сохраняет/повышает (деградация).
