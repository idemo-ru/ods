## 1.3.9.3. Термин и формулировка {#1-3-9-3}
**Наблюдатель** — локальный embedded ChangeOperator системы, обеспечивающий доступ к контекстам и взаимодействие со средой (родительской системой), фиксирующий состояния, изменения и причинные цепочки для формирования Experience Graph.

## 1.3.9.4. Область применения {#1-3-9-4}
Для всех систем с evaluate в ChangeFlow. Обязателен для накопления локального опыта.

## 1.3.9.5. Классификация / Категория {#1-3-9-5}
Системное свойство → Локальный сенсор/фиксатор → Источник опыта → Интерфейс со средой.

## 1.3.9.6. Атрибуты / свойства {#1-3-9-6}
- Локальность: привязан к экземпляру системы.
- Ограниченность: конечная память, вычислительные ресурсы, стратегия паттернов.
- Встраиваемость: реализуется как ChangeOperator.
- Причинная фиксация: Intent → Context → Operators → Result.
- Coarse-graining: неизбежное нарушение симметрии альтернатив из-за ограничений.
- Иерархичность: Локальный Наблюдатель подчинён C_coord родительской системы, получая контексты из C_Layers.

## 1.3.9.7. Связи с другими терминами / определениями {#1-3-9-7}
- Родительские: ChangeOperators, ChangeFlow (evaluate).
- Дочерние: Experience Graph.
- Связанные: 
  - Опыт (локальный источник).
  - Viewpoint (ограничен наблюдателем).
  - C_Layers/C_coord: Локальный Наблюдатель интерпретирует внешние контексты через C_coord родительской системы; C_coord выступает как Наблюдатель высшего уровня для подсистемы.

## 1.3.9.8. Примеры и иллюстрации {#1-3-9-8}
- Организм: сенсорные рецепторы фиксируют стимулы → локальный опыт.
- LLM: attention/tokens как ограниченный наблюдатель runtime.
- Физический прибор: фиксирует одну траекторию из множества.

## 1.3.9.10. Заключение {#1-3-9-10}
Наблюдатель — источник локальности, нарушения симметрии и интерфейс со средой, необходимый для формирования опыта в ограниченных системах.
