## 1.3.6.3. Термин и формулировка {#1-3-6-3}
Вероятность - обязательный Embedded ChangeOperator любой системы.

## 1.3.6.4. Область применения {#1-3-6-4}
Любая система классов 1-6. В сдучае недоступности других ChangeOperators для фазы decide() ChangeFlow системы является оператором по умолчанию.

## 1.3.6.5. Классификация / Категория {#1-3-6-5}
```
Термин помещается в систему категорий или типов.
Может включать иерархию понятий, связь с более общими или частными понятиями.
```

## 1.3.6.6. Атрибуты / свойства {#1-3-6-6}
```
Формальный список характеристик или признаков, которые обязательно должны выполняться.
В стандартах (ISO, IEEE, OMG) часто указывают обязательные vs. опциональные атрибуты.
```

## 1.3.6.7. Связи с другими терминами / определениями {#1-3-6-7}
```
Поясняет взаимосвязь в онтологической или концептуальной модели.
Например: родительский/дочерний термин, синонимы, смежные понятия.
```

## 1.3.6.8. Примеры и иллюстрации {#1-3-6-8}
```
Демонстрируют правильное использование термина.
В стандартах (например, ISO 704:2009 «Terminology work») считаются опциональными, но сильно повышают ясность.
```

## 1.3.6.10. Заключение {#1-3-6-10}

```
Следствия, примечания, другая резюмирующая информация.
```
