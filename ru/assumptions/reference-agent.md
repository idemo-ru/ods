# Допущение 04. Эталонный агент для измерения субъективности

## Формулировка допущения

В рамках ODS допускается существование виртуального эталонного агента **E** — абстрактной системы, обладающей следующими свойствами в заданном контексте **C**:

1. E обладает максимально полным и релевантным набором ChangeOperators для области, цели и ограничений контекста C.  
2. Для каждого инструмента i:  
   – Rᵢ⁽ᶜ⁾(E) = 1.0  
   – Qᵢ⁽ᶜ⁾(E) = 1.0 (или максимально достижимое качество в текущем состоянии знаний)  
3. E всегда выбирает оптимальную (по критериям результативности R) траекторию в ChangeFlow.

## Назначение эталонного агента

- Служит фиксированной точкой отсчёта для вычисления абсолютной субъективности любой реальной системы A:  
  **S₍A₎ = S(A, E)**  
- Позволяет сравнивать субъективность/креативность систем между разными задачами и контекстами.  
- Делает метрику S объективно интерпретируемой (вместо относительного сравнения двух произвольных систем).

## Следствия

Следствие 05:  
При одинаковой результативности R(A) ≈ R(E) более высокое значение S₍A₎ однозначно указывает на более творческий/нестандартный подход системы A.

Следствие 06:  
Системы с S₍A₎ → 0 при R(A) → R(E) демонстрируют максимально шаблонное, воспроизводимое поведение.

## Ограничения допущения

- Эталонный агент E — чисто вычислительная конструкция, не обязан быть физически реализуемым.  
- При изменении границ контекста C или прогрессе знаний состав и качество инструментов E пересчитываются.
